# World configuration

`WorldConfig` (in `@evo/contracts`) describes everything that shapes a world except its **seed**. Defaults and validation live in `@evo/config`.

```ts
import { resolveWorldConfig } from '@evo/config'

const config = resolveWorldConfig({ organisms: { initialCount: 10 } })
```

`resolveWorldConfig` merges partial overrides onto `DEFAULT_WORLD_CONFIG` section by section, validates the result, and either returns a fresh mutable copy or throws a `ConfigValidationError` that lists **every** problem:

```text
Invalid world configuration:
  - timestep must be greater than zero
  - resources.spawnRate must be nonnegative
```

`validateWorldConfig(value: unknown)` checks a complete configuration of unknown origin (such as parsed JSON) and returns `{ ok, errors }`. Validation only reports; it never repairs or clamps a value. NaN and infinities are rejected, and unknown property names are reported so typos are caught.

Seeds are validated separately with `validateSeed`: an integer in `[0, 4294967295]`.

Units: time is in **seconds** (one tick advances time by `timestep`), distance in world units, energy in arbitrary units.

| Field                                                                   | Rule                                                                                        | Meaning                                                                                                      |
| ----------------------------------------------------------------------- | ------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| `timestep`                                                              | > 0                                                                                         | Seconds of simulated time per tick                                                                           |
| `maxPopulation`                                                         | integer, > 0                                                                                | Population ceiling (births are refused at the cap)                                                           |
| `extinctionPolicy`                                                      | `'stop'` (only value implemented)                                                           | What happens when the population reaches zero                                                                |
| `environment.width`, `.height`                                          | > 0                                                                                         | World rectangle                                                                                              |
| `organisms.initialCount`                                                | integer, >= 0, <= `maxPopulation`                                                           | Founders created at tick 0                                                                                   |
| `organisms.initialEnergy`                                               | > 0, <= `maxEnergy`                                                                         | Founders' starting energy                                                                                    |
| `organisms.maxEnergy`                                                   | > 0                                                                                         | Founder energy capacity (an organism's capacity scales with its body size gene); overflow is wasted          |
| `organisms.radius`                                                      | > 0, < half the smaller world dimension                                                     | **Founder baseline** body radius                                                                             |
| `organisms.maxSpeed`                                                    | >= 0                                                                                        | **Founder baseline**, units per second                                                                       |
| `organisms.maxTurnRate`                                                 | >= 0                                                                                        | **Founder baseline**, radians per second                                                                     |
| `organisms.sensorRadius`                                                | > 0                                                                                         | **Founder baseline** perception distance                                                                     |
| `organisms.wanderJitter`                                                | >= 0                                                                                        | **Founder baseline** wander heading change, radians per second                                               |
| `organisms.basalCost`                                                   | >= 0                                                                                        | **Founder baseline** energy per second for being alive                                                       |
| `organisms.movementCost`                                                | >= 0                                                                                        | **Founder baseline** energy per second per squared unit of speed                                             |
| `organisms.turningCost`                                                 | >= 0                                                                                        | **Founder baseline** energy per second per squared radian turned                                             |
| `organisms.sensorCost`                                                  | >= 0                                                                                        | Energy per second for sensing at the baseline `sensorRadius` (scales with an organism's own radius)          |
| `organisms.maturityAge`                                                 | > 0, < `senescenceAge`                                                                      | **Founder baseline** seconds until a juvenile becomes mature                                                 |
| `organisms.senescenceAge`                                               | > `maturityAge`, < `maxAge`                                                                 | **Founder baseline** seconds until a mature organism becomes senescent                                       |
| `organisms.maxAge`                                                      | > `senescenceAge`                                                                           | **Founder baseline** seconds until death by age                                                              |
| `organisms.hue`                                                         | [0, 1)                                                                                      | **Founder baseline** hue in turns (cosmetic)                                                                 |
| `organisms.juvenileSizeScale`                                           | (0, 1]                                                                                      | Juvenile capture radius and energy capacity multiplier                                                       |
| `organisms.juvenileSpeedScale`                                          | (0, 1]                                                                                      | Juvenile `maxSpeed` multiplier                                                                               |
| `organisms.juvenileMetabolicScale`                                      | (0, 1]                                                                                      | Juvenile metabolic cost multiplier                                                                           |
| `resources.initialCount`                                                | integer, >= 0, <= `maxCount`                                                                | Resources at tick 0                                                                                          |
| `resources.maxCount`                                                    | integer, >= 0                                                                               | Cap on simultaneous resources                                                                                |
| `resources.spawnRate`                                                   | >= 0                                                                                        | Expected new resources per second                                                                            |
| `resources.energyValue`                                                 | > 0                                                                                         | Energy one resource provides                                                                                 |
| `resources.radius`                                                      | > 0, < half the smaller world dimension                                                     | Resource radius                                                                                              |
| `reproduction.minEnergy`                                                | > 0                                                                                         | **Founder baseline** energy required to attempt reproduction                                                 |
| `reproduction.offspringInvestment`                                      | > 0                                                                                         | **Founder baseline** energy each parent gives the child; `parent pays = investment * (1 + overheadFraction)` |
| `reproduction.overheadFraction`                                         | >= 0                                                                                        | Fraction of the investment lost in the transfer                                                              |
| `reproduction.cooldown`                                                 | >= 0                                                                                        | **Founder baseline** seconds before a parent may reproduce again                                             |
| `reproduction.searchRadius`                                             | > 0                                                                                         | **Founder baseline** distance within which a partner is sought                                               |
| `history.maxEvents`                                                     | integer, >= 0                                                                               | Retained events (`0` keeps none)                                                                             |
| `history.eventDetail`                                                   | `'essential'` or `'verbose'`                                                                | Whether per-tick movement and energy events are emitted                                                      |
| `history.maxHistoricalOrganisms`                                        | integer, >= 0                                                                               | Retained historical organism records (ring buffer)                                                           |
| `genetics.mutationRateScale`                                            | >= 0                                                                                        | Multiplies every gene's mutation rate; `0` disables mutation                                                 |
| `genetics.mutationStrengthScale`                                        | >= 0                                                                                        | Multiplies every gene's mutation standard deviation                                                          |
| `genetics.blendAlpha`                                                   | >= 0                                                                                        | Blend-crossover extension past the parents' values                                                           |
| `genetics.brain.inputSize`, `.hiddenSize`, `.memorySize`, `.outputSize` | integer, > 0                                                                                | Fixed brain architecture shared by every organism                                                            |
| `genetics.brain.initialWeightStd`                                       | > 0                                                                                         | Standard deviation of founders' random weights                                                               |
| `genetics.brain.weightMutationRate`, `.weightMutationStd`               | rate in [0, 1], std >= 0                                                                    | Per-weight mutation probability and size                                                                     |
| `genetics.learning.*`                                                   | learning rate > 0; discount, trace decay, exploration, risk, novelty, persistence in [0, 1] | Founder baseline learning genes (carried until Phase 5)                                                      |
| `genetics.learningInheritance.mode`                                     | `'baldwinian'`, `'partial'` or `'lamarckian'`                                               | How learned weights are inherited (wired in Phase 5)                                                         |
| `genetics.learningInheritance.fraction`                                 | [0, 1]                                                                                      | Share of learning inherited in `'partial'` mode                                                              |
| `genetics.genes.<path>`                                                 | optional `{min, max, mutationRate, mutationStd}`                                            | Per-gene overrides of the default ranges and rates; the ordered life-stage ranges must not overlap           |

Cross-field rules also include: `reproduction.offspringInvestment * (1 + overheadFraction) <= reproduction.minEnergy`, and `2 * reproduction.offspringInvestment <= organisms.maxEnergy`. The gene table with default ranges is in [docs/genetics/genome.md](../genetics/genome.md); `organisms.*` and `reproduction.*` above are only the founder baseline, since each organism reads its traits from its own genome.

The defaults are provisional and tuned by the engine's scenario tests. Determinism tests pin their configuration explicitly, so changing a default never changes a golden hash. The configuration is not part of the state hash (see [determinism.md](determinism.md)).
